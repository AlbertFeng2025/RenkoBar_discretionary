How to use this page
  1. Copy this file (Renko_Recorder_Viewer.html) anywhere you like — e.g. into the Log Folder (default C:\temp) so it sits next to the logs.
  2. Double-click it to open it in Chrome or Edge, click Choose log folder and pick the indicator's Log Folder. Next time, just click Reconnect.
  3. Leave it open — it re-reads every 1.5 s. NinjaTrader keeps writing whether this page is open or not.
  4. Fresh start (optional): delete the old files ending in _state.json from the Log Folder. Running recorders write a new one on their next brick. Keep the .csv files — they are your history.

Each recorder writes <LogBaseName>_state.json after every brick. The line with a dark left edge is the deepest (money) layer. "0s in a row" = how many 0's follow the last 1 of that string. Market speed = average seconds per brick over the last N bricks of this session (set in the indicator, "Common 5. Speed"); "this brick open" counts up live from the last brick close.
